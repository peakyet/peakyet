03 About

What is this?

A personal, evolving knowledge base. The idea is to write down things the way I'd want them explained — with the motivation first, the reasoning laid out, and the details where they're actually needed.

  • Breadth first. Notes span mathematics, control, optimization, robotics, AI, and code.
  • Intuition before formalism. Build the mental model, then nail the equations.
  • Always growing. This is a living document, not a finished product.

If something reads as unclear, it's probably a note that needs another pass — the gaps are as much part of the map as the notes themselves.
